# ChoiceVishwa Services

A simple multi-page website made with HTML, CSS, Bootstrap, and vanilla JavaScript.

## Run the website

Install the project tools once:

```sh
npm install
```

Start the local website:

```sh
npm run dev
```

Open the local address shown in the terminal. The About page is available at `/about.html`.

## Main files

- `index.html` contains the counselling services page.
- `about.html` contains the About page.
- `src/ServicesPage.css` contains the website's custom design and responsive styles.
- `src/index.css` contains the basic page styles.
- `src/script.js` handles the service selector, mobile menu, and scroll-to-top button.
- `public/assets/` contains the site logo and illustration.

Bootstrap's stylesheet provides its layout and utility classes. The existing custom CSS is kept to preserve the finished website design.
